# Operator model policy

Automatic model Council selection, benchmark qualification, promotion and AIMS/RAMS synchronisation are retired. Production uses configured model defaults and existing fallback routes.

Provider authentication, account availability, request failures, usage/cost reporting and lifecycle/catalogue information remain available. Manual benchmark ranking is advisory and cannot rewrite service assignments. Explicit premium overrides retain their independent operator justification controls. Missing evaluation history does not make a healthy deployment fail.

Monthly reviews aggregate operational health, usage, costs and execution outcomes and archive the report to R2/D1. They do not run a model Council. Repository and content-quality councils remain separate.
